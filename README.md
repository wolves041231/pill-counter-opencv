# Pill/Capsule Counter (classical OpenCV)

Counting pills, candies and beans in photos using classical computer vision only, no deep learning.

**Status:** Day 2 done (blurring, thresholding and morphology compared across 5 backgrounds). Next: contours and counting.

**Dataset:** 28 photos on 7 different backgrounds, from 6 to about 40 objects, including touching and overlapping cases. Inventory in `pill_counter_dataset.xlsx`.
